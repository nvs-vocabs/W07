# [W07](http://vocab.nerc.ac.uk/collection/W07/current/)
SensorML Identification Section Terms

Public repository for discussions related to terms used in SensorML to identify an observation system.

## Request for new terms and ways to contribute
- Requests for a new W07 can be submitted as [regular issues](https://github.com/nvs-vocabs/W07/issues) in this repository or emailed to vocab.services-at-bodc.ac.uk.

- Reporting errors or suggestions for improving content can be also be submitted as above.
